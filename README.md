# Synk Skills

As skills que a Synk Lab usa para criar com o Claude: diagramação de posts no Figma, DNA de marca, direção de imagem, carrossel, desdobramento para redes, vídeo e campanha.

## Instalar com um comando

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/kalango99/synk-skills/main/install.ps1 | iex
```

**macOS / Linux (Terminal):**

```bash
curl -fsSL https://raw.githubusercontent.com/kalango99/synk-skills/main/install.sh | bash
```

**Ou cole no Claude Code / no agente do Antigravity:**

> Instale as skills do repositório https://github.com/kalango99/synk-skills rodando o instalador do meu sistema (install.ps1 no Windows, install.sh no Mac) e me confirme a lista do que ficou em ~/.claude/skills.

Depois feche e abra o Claude Code.

## O que vem no pacote

| Skill | Para que serve |
| --- | --- |
| `synk-posts` | Método de diagramação de carrossel, post e story no Figma. Mede as peças aprovadas, varia o modelo de cada tela e confere os vícios de máquina. |
| `synk-dna` | DNA criativo da marca: identidade visual, tom de voz, fotografia, anti-padrões. |
| `synk-image` | Direção fotográfica e render de imagem: câmera, lente, luz, composição. |
| `synk-carrossel` | Pauta, headline e copy de carrossel, com render das telas. |
| `synk-social` | Desdobra uma peça em Instagram Feed, Stories e LinkedIn, cada uma nativa. |
| `synk-cinematic` | Campanha e product shot cinematográfico, frames aprovados antes do vídeo. |
| `synk-motion` | Reels e motion graphics pelo terminal com Remotion. |
| `synk-buzzy` | Vídeo e imagem pelo Buzzy, do brief ao render. |
| `synk-ad-cinema` | Anúncio de produto com linguagem de cinema. |
| `synk-team` | Time de agentes criativos: do brief ao handoff da campanha. |
| `synk-roteiro-reels` | Roteiro de Reels cena a cena, legenda, hashtags e trilha. |

## Atualizar

Rode o mesmo comando de novo. Ele substitui as skills Synk pelas versões mais novas e não mexe em nenhuma outra skill sua.
